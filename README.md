First, run the development server:


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## Auth configuration

Create a `.env.local` file from `.env.example` and set:

- `JWT_SECRET` to a random secret with at least 32 characters.
- `AUTH_USERNAME` to your login username.
- `AUTH_PASSWORD_HASH` in the format `<salt>:<scrypt_hash_hex>`.

You can generate `AUTH_PASSWORD_HASH` from a password with:

```bash
node -e "const c=require('node:crypto');const salt=c.randomBytes(16).toString('hex');const hash=c.scryptSync(process.argv[1],salt,64).toString('hex');console.log(salt+':'+hash)" "your-password"
```
